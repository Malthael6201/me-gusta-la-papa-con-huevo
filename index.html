01 — CONCEPTOS BÁSICOS

¿Qué son Git y GitHub?

Git

Es un sistema de control de versiones. Permite registrar los cambios realizados en los archivos de un proyecto y volver a versiones anteriores cuando sea necesario.

GitHub

Es una plataforma en línea donde podemos almacenar repositorios Git, compartir proyectos y colaborar con otras personas.

02 — PREPARACIÓN

Instalación y configuración

  1. Descarga Git desde git-scm.com e instálalo en tu computadora.
  2. Abre Git Bash desde el menú de inicio de Windows.
  3. Comprueba la instalación con el comando git --version.
  4. Configura tu nombre y correo electrónico:
git config --global user.name "Tu Nombre"
git config --global user.email "tu_correo@ejemplo.com"

03 — TRABAJO LOCAL

Comandos básicos de Git

Abre Git Bash dentro de la carpeta de tu proyecto y utiliza estos comandos en orden:

git initInicializa un repositorio Git en la carpeta actual.
git statusMuestra el estado de los archivos y los cambios.
git add .Prepara los cambios para guardarlos en un commit.
git commit -m "Descripción"Guarda una versión del proyecto con un mensaje descriptivo.
git log --onelineMuestra el historial de commits realizados.

04 — HISTORIAL DEL PROYECTO

Ejemplo de tres commits

Un commit representa un punto guardado en el historial del proyecto. Para esta práctica se deben realizar tres commits con descripciones claras.

COMMIT 1

Crear la estructura inicial

git add .git commit -m "Crear estructura inicial"
COMMIT 2

Agregar contenido a la guía

git add .git commit -m "Agregar contenido de Git"
COMMIT 3

Mejorar el diseño de la página

git add .git commit -m "Mejorar diseño de la guía"

Importante: realiza cada commit después de un cambio real en los archivos. No ejecutes los tres commits seguidos sin modificar el proyecto.

05 — PUBLICAR EL PROYECTO

Crear un repositorio en GitHub

  1. Entra en github.com e inicia sesión o crea una cuenta.
  2. Selecciona New repository.
  3. Escribe un nombre, por ejemplo U5_GitHub, y selecciona la opción Public.
  4. Crea el repositorio sin agregar archivos iniciales si tu proyecto local ya está preparado.
  5. Conecta tu proyecto local con la dirección de tu repositorio:
git branch -M main
git remote add origin https://github.com/USUARIO/U5_GitHub.git
git push -u origin main

Reemplaza USUARIO por tu nombre de usuario de GitHub y utiliza la dirección real de tu repositorio.

06 — REPASO

¡Tu proyecto está listo para compartirse!

Antes de entregar, verifica que el repositorio sea público, que contenga los archivos del proyecto y que se puedan ver los tres commits en el historial.

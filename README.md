# U5 - Guía básica de Git y GitHub

Proyecto web sencillo para la práctica U5 - Repositorio en GitHub.

## Archivos
- `index.html`: contenido de la guía.
- `estilos.css`: diseño y adaptación a pantallas pequeñas.
- `script.js`: interacción mediante el DOM.

## Cómo abrir
Abre `index.html` con tu navegador web.

## Contenido
La guía explica qué son Git y GitHub, la instalación y configuración inicial, comandos básicos, el ejemplo de tres commits y cómo publicar un repositorio público en GitHub.

Los tres commits deben realizarse después de cambios reales en los archivos. El ejemplo de mensajes que aparece en la página es orientativo.
